# Brand logos

Drop brand logo images here to replace the auto-generated monogram tiles in the
homepage "Browse by brand" grid.

- Filename must match the brand `slug` in `frontend/lib/brands.js`, e.g. `hino.png`.
- Use a square, transparent PNG (~96×96 or larger). It's shown on a white tile.
- Until a file exists for a brand, a brand-coloured monogram is shown instead.

Only add logos you have the right to use.
